\section{Composantes d'une cellule électrochimique}

\Q Donner une définition et expliciter le rôle joué par les composantes suivantes : 
\begin{itemize}
\item électrode
\item demi-pile
\item solvant
\item électrolyte
\item isolateur
\item collecteur de courant
\end{itemize}

Dans la suite de l'exercice, il s'agira d'identifier le rôle joué par chacune des composantes de différentes technologies de piles.
